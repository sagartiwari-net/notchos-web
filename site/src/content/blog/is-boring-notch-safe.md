**Is Boring Notch safe?** It can be — if you install from the **official open-source project**, verify the release, and understand the permissions it asks for. “Safe” is not a slogan; it is a checklist.

**NotchOS** is our product. We are not affiliated with Boring Notch. Prefer primary sources: the [Boring Notch GitHub organization/repo](https://github.com/TheBoredTeam/boring.notch).

## Checklist before you install any free notch app

1. **Official source only** — GitHub Releases from the real org, not random DMG mirrors or “cracked” copies.  
2. **Gatekeeper** — unsigned or ad-hoc builds may warn; that is a signal to slow down, not to disable security blindly.  
3. **Permissions** — Accessibility, Screen Recording, Calendar, etc. should match features you actually enable.  
4. **Read recent issues** — active trackers show how the project responds to bugs.  
5. **Prefer notarized apps** when you want less Gatekeeper friction — NotchOS ships a signed/notarized DMG from [our download page](/download).
