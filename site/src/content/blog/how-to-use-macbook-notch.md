People searching **how to use MacBook notch** usually want one of two things: hide the cutout, or put it to work.

## Option A — Hide the notch

Wallpaper tricks and “notch hiding” apps darken the menu-bar band so the camera housing blends in. That removes the visual gap; it does not add tools.

## Option B — Use a Mac notch / Dynamic Island app

Install an app that expands the notch into controls:

- Music / Now Playing  
- File tray  
- Clipboard history  
- Timers that stay visible when closed  

**NotchOS** does that as a glass island on Apple silicon (macOS 26 or later). [Dynamic Island guide](/blog/dynamic-island-for-macbook) · [Trial](/trial)

## Quick start with NotchOS

1. [Download](/download) and open the app.  
2. Start the 7-day trial in-app.  
3. Hover/click the notch; switch faces from the tab strip.  
4. Grant permissions only for tools you open ([permissions](/blog/mac-notch-app-permissions)).
