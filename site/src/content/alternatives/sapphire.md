**Sapphire** is an open-source Mac notch / Dynamic Island project with a wide surface — media, file shelf, window snap, and **Android Nearby Share**-style transfers, plus optional paid tiers for some AI/live features. Start at the [GitHub repository](https://github.com/cshariq/Sapphire) and confirm current install + pricing pages.

**NotchOS** is our product. Unaffiliated with Sapphire.

## Strengths

- Broad “everything app” ambition under an open-source license  
- Android ↔ Mac sharing is a real differentiator in this category  
- Active development — check release notes often  

## Gaps / trade-offs

- More permissions and surface area than a minimal island  
- Paid tiers for some features can blur “is it free?”  
- Packaging (pkg vs notarized DMG) differs by project
